# 🇵🇪 QUIZ PERÚ

Mini juego de preguntas sobre las **capitales de los departamentos del Perú**, pensado para niños y adolescentes de 10 a 15 años.

## ¿Cómo se juega?

1. Presiona **¡Jugar!**
2. Aparece una pregunta con **2 alternativas**: una correcta y una incorrecta.
3. Tienes **3 segundos** para elegir. Si no eliges a tiempo, cuenta como incorrecta.
4. Cada respuesta correcta suma **1 punto**; cada incorrecta suma 0.
5. Son **5 preguntas al azar**. Al final verás cuántas acertaste y cuántas fallaste.

## Características

- Una sola página: HTML, CSS y JavaScript en el mismo archivo.
- Sin librerías externas ni backend.
- Fondo de Machu Picchu dibujado en SVG, con nubes animadas.
- Se adapta a computadora y celular, sin necesidad de scroll.
- Funciona sin conexión a internet.

## Cómo usarlo en tu computadora

Descarga el proyecto y abre el archivo `index.html` con doble clic en tu navegador.
